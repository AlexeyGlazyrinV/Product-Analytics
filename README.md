# Product Analytics

Case studies applying statistical testing and product metrics to real-world product decisions, focused on mobile products and gaming.
Built while transitioning into product analytics.

## Cases

### 1. Cookie Cats - Gate Placement A/B Test
Does moving the level-gate from 30 to 40 affect player retention (mobile game)?
Two-proportion z-test / chi-square test on 90k+ players.
Found a statistically significant 4.3% relative drop in Retention D7 (p=0.0016) - recommend against shipping the change.

## Tools
Python (pandas, numpy, scipy, matplotlib), SQL, statistical testing (A/B testing, chi-square, z-tests)
